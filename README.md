# Promoter Seeker
Software designed to find promoter sequences in Trichoderma atroviride. Solution for Hack The Promoter hackaton.

## Environment initialisation

To create environment:
```sh
uv sync
```

Then to activate it:
To create environment:
```sh
source .venc/bin/activate
```

# Dataset

[Reference genome](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_020647795.1/) of Trichoderma atroviride use dedicated ncbi ommand to download or use ftp.
